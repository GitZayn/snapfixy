How to make a PNG transparent

Published 18 November 2026 · SnapFixy team · 4 minute read

A transparent PNG is one of the most useful files you can have: a logo that sits cleanly on any background, a product photo that drops neatly into a slide, a sticker that actually looks like a sticker. Yet people run into the same problem again and again — they remove the background, save the file, and the white box comes back. Transparency is not something you draw on. It is a property of the file itself, and it only survives if you use the right format and the right steps.

What makes a PNG transparent?

Every PNG can carry a fourth colour channel, called the alpha channel, alongside the usual red, green and blue. Where the alpha channel says a pixel is fully transparent, nothing is drawn there at all — whatever is behind the image simply shows through. That is why it works on a dark slide, a coloured web page and a printed flyer alike: there is no white box to hide, because there is no background baked into the file.

JPG cannot do this. A JPG has no alpha channel, so the moment you save a transparent image as a JPG, the empty areas fill with white. That is the most common reason a "transparent" image turns out not to be one — the background was removed correctly, then the file was saved in a format that cannot hold the result.

If your PNG already has a white background

Some PNGs look transparent but are not: open one and you see a logo on white, because the white background is part of the file itself. Converting the file will not help — turning a JPG into a PNG only changes the container, it removes nothing. The white has to be taken out, and the same background remover does that job: drop the PNG in, let it cut the white away, and download the result. If you started with a JPG, run it through the image converter first.

How to check your PNG is really transparent

Before you use the file anywhere important, check it. Open it in your browser — most browsers show transparent areas as a grey-and-white chequered pattern. Or drop it onto a coloured background in a slide deck: if the colour shows through around your subject, the transparency is real. If you see a solid white rectangle instead, the file was saved as a JPG somewhere along the way, or the background was never removed.

Common mistakes that kill transparency

  • Saving as JPG. The number one culprit. JPG has no alpha channel, so transparency is lost the instant you save in that format.
  • Taking a screenshot of a transparent image. A screenshot captures what is on screen, flattened onto a background — the transparency does not survive.
  • Re-saving in an old editor. Some older or basic editors flatten transparency when they save. If your PNG suddenly has a white background, check the app you last saved it in.
  • Exporting with a background layer switched on. In tools like Canva, a white background element behind your design gets baked into the export. Turn it off before you download.

Quick questions

Can I make a JPG transparent? Not directly — JPG cannot hold transparency. Convert the image to PNG first, then remove the background, and keep the result as a PNG.

Does a transparent PNG work everywhere? In almost every modern browser, app and design tool, yes. A few older programs flatten it, so if one app shows a white box, try another before blaming the file.

Will a transparent PNG be a bigger file? Usually a little, because the alpha channel is extra data. Running it through the image compressor keeps it small for the web.

Can I add a white background back later? Yes. Place the transparent PNG over a white background in any editor or slide deck — you are never locked in.
